### CV Reviewer
A full-stack AI-powered CV reviewer for students and junior developers. Users register, log in, and upload a PDF CV to receive structured feedback — including a score, strengths, weaknesses, missing keywords, and actionable suggestions generated via the Google Gemini API. Features JWT authentication and five user-selectable themes that persist between sessions.

**Stack:** React · Node.js · Express · Python · Google Gemini API · Vercel

🔗 Live Demo: [cv-reviewer.vercel.app](https://cv-reviewer.vercel.app)  
🔗 Repository: [CV-Reviewer](https://github.com/FrancoisleRouxDev/CV-reviewer)
